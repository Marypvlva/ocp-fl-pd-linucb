# Скачать результаты через HTTPS

В браузерной консоли координатора после завершения серии выполните

```bash
cd /opt/research/ocp-fl-pd-linucb
.venv/bin/python deploy/timeweb/summarize.py results/timeweb-pilot
.venv/bin/python deploy/timeweb/export.py --out results/timeweb-pilot \
  --cert deploy/timeweb/state/tls.crt --key deploy/timeweb/state/tls.key
```

Сервер напечатает случайный пароль и будет работать до Ctrl+C. В панели Timeweb разрешите входящий TCP 8443 только с вашего текущего IP. В браузере Mac откройте `https://IP_КООРДИНАТОРА:8443/results.zip`. Введите логин `research` и напечатанный пароль. Сертификат стенда самоподписанный. До добавления исключения сравните его SHA-256 с отпечатком из доверенной браузерной консоли координатора. Отпечаток сертификата в DER-формате

```bash
openssl x509 -in deploy/timeweb/state/tls.crt -noout -fingerprint -sha256
```

Для curl скопируйте публичный tls.crt через консоль или браузер в локальный файл и используйте `--cacert tls.crt -u research`. Пароль вводится интерактивно. SSH с Mac для скачивания не требуется. Архив содержит разрешённые форматы исследовательских журналов. Ключи, секреты состояния развёртывания и SQLite-журнал сервиса в экспорт не попадают. Сами файлы результатов проверяйте на отсутствие добавленных вручную секретов перед передачей другим людям.

После скачивания остановите сервер Ctrl+C и закройте правило TCP 8443 в панели. Исходные журналы и budget.sqlite сохраняются на координаторе. Обработка summary возвращает код 2, если часть эпизодов не завершена, и перечисляет их. Такие эпизоды должны оставаться видимыми при подготовке статьи.

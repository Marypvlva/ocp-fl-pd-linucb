# Возраст телеметрии при выборе действия: протокол

Протокол задан до основной серии. Предыдущая поправка согласовала отчёт и
стоимость для обучения, но ускорения относительно исходного алгоритма не показала.
Теперь меняется именно prior стоимости передачи при выборе действия.

## Алгоритм и доступная информация

`network_freshness` наследует `network_aligned`. Из доставленных отчётов хранит
последние 16 различных capture ID. Для возраста d вес последнего отчёта 1/(1+d),
остальное — среднее transfer prior по этой истории. Это простая эвристика, не
калиброванная модель вероятности текущего состояния. Число 16 — фиксированный
инженерный размер буфера, не передаваемая длительность фазы.

При свежем отчёте алгоритм совпадает с aligned на общих исходах. Повтор одного
отчёта не увеличивает историю. Success feedback немедленный, residual — по
совпадающей метке захвата, только для выбранного действия. Exploration 5%, priors,
scoring и стоимость переключения прежние. Каталог профилей, истинная текущая
сеть, будущие состояния и результаты невыбранных действий планировщику не доступны.
Параметры после основной серии не подбираются на её данных.

## Основная серия

12 участников, 50260 параметров, модели 16…23, learning rate 0.5, target loss 0.22.
8 блоков; exact и stale_noise × freshness/aligned/prior, плюс один общий
фактический F+P на блок. **56 запусков**, все 7 случаев перемешаны внутри блока.
Модели и шаг прежние, независимыми являются новые сетевые сценарии, отказы,
шум, exploration и порядок. Отбор удачных моделей по новой серии запрещён.

Новые трассы seed 83026+r, faults +1000, profiles +2000, sensor +3000,
planner +11000, порядок +20000. Фазы 4–8 попыток, 40 MB/s, 2 ms/сообщение.
stale_noise: лаг 2 попытки, lognormal σ=0.35, нулевой флаг unlimited сохраняется.
До 160 попыток; deadline 1.5 s, RPC 1.2 s, switching wait 0.025 s.

Единственный первичный контраст: **freshness − aligned в stale_noise**.
Отрицательное значение означает ускорение. Bootstrap среднего по полным парам:
20000 выборок, seed 184026. Остальные контрасты описательные, без коррекции
множественных сравнений; расчёта мощности нет. Недостигнутый порог не заменяется
временем остановки, возможное смещение полных пар явно сообщается.

Smoke отдельно: seed 82026, 4/8/12 участников, hidden=16, 4 попытки, clean,
чередование профилей каждую попытку. Это проверка интеграции, не оценка T_epsilon.

## Аудит

Протокол/исходники фиксируются до основной серии через `project.py freeze`.
Source snapshot основной серии сверяется с этой фиксацией. Воспроизводятся все
решения, статистика, matched residual и независимо — история/веса смеси.
Проверяется отсутствие будущих отчётов и повторного обучения по одному capture ID.
Метрика — непрерывное физическое T_epsilon, без startup/исходной validation/warmup;
предыдущая телеметрия, валидации, выбор и журналирование входят в последующее время.

Результаты предыдущих серий сохраняются отдельно. Прогресс и отрицательные исходы
не скрываются. Этот опыт не проверяет новые инициализации, WAN, реальные сетевые
пробы, потерю отчётов или неизвестные/поддельные timestamps. Один Mac, честные
участники; проверяется сумма, а не честность локальных градиентов.

Данные: results/tcp_telemetry_freshness_20261103T064112Z_79c4d344/.
Целевого качества достигли 56/56 запусков;
5082 TCP-раундов, 4011 принятых обновлений,
0 тайм-аутов. Пройдено 76 тестов.
Первичный freshness−aligned в stale_noise: -0.762 s,
описательный bootstrap 95% [-1.231; -0.338].
На новых трассах freshness ускорил достижение качества относительно aligned. Выигрыш над сильным фиксированным F+P оценивается отдельно и не следует из первичного контраста.

Этот раздел добавлен после анализа; предшествующая часть протокола и код
зафиксированы до выполнения. Старые серии не объединены с новой.

Вторичное сравнение в stale_noise: freshness−F+P = +0.492 s, описательный 95% интервал [+0.340; +0.689]. Фиксированный F+P в этой серии быстрее; общего превосходства адаптации не показано.

2. [Гипотезы, сценарии, параметры и статистика](EXPERIMENTAL_DESIGN_RU.md).

5. [Обновление и точные команды каждого семейства](TIMEWEB_EXPERIMENTS_RU.md).

Модули находятся в `experiments/collector_v3/kit/`: `program.py` создаёт отдельный план, `program_suite.py` — блокированное семейство, `analysis_program.py` проверяет/анализирует данные, `replay_program.py` реконструирует тот же контроллер, `mechanisms_program.py` разбирает стадии и ресурсы. При `plan` сетевые/облачные эксперименты не выполняются. `run` предназначен для явного запуска оператором после проверки плана.

Исходный набор v0.6.1 в отдельном Draft-релизе не изменяется и автоматически не публикуется. Графики отсутствующих сеток/метрик не выдумываются. Основные научные запуски и окончательная интерпретация выполняются автором исследования.

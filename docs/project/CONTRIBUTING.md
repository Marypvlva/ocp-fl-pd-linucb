# Разработка и воспроизведение

## Установка

Поддерживаемый Python — 3.13; проверено на macOS arm64 3.13.7. Существующую `.venv`
не удалять. Из нового checkout:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m adaptive_planning doctor
```

Editable-установка использует конфигурации/данные относительно checkout. Обычная
установка wheel в site-packages пока не является поддерживаемым способом запуска
исследовательских серий. `requirements-lock.txt` сохраняет точную текущую
среду; минимальные рабочие зависимости заданы в pyproject.toml/requirements.txt.

## Повседневная проверка

```bash
.venv/bin/python -m ruff format --check adaptive_planning tests project.py
.venv/bin/python -m ruff check adaptive_planning tests project.py
.venv/bin/python -m adaptive_planning test
.venv/bin/python -m adaptive_planning smoke
```

Архивные исходники не форматируются и не используются рабочим пакетом.
`python -m legacy --list` показывает их; явный запуск копирует их в новую
результирующую папку. Старые плоские команды воспроизводятся по source snapshot.

## Исследовательский цикл

Сначала JSON-конфигурация и Markdown-протокол: гипотеза, первичный контраст, seed,
модели, число повторов, цензурирование. Затем freeze → study → verify → report.
Каждая папка новая; повтор на тех же seed — воспроизведение, а не новая выборка.
Не передавать планировщику Fault/режимы/будущее и не выдавать расчётную стоимость
за измеренное время. Фиксированные стратегии измеряются реально.

Время достижения порога не заменяется временем остановки; доля достигших обязательна.
Изменения после просмотра проверки требуют новых сценариев и фиксации протокола.
Нельзя скрывать отрицательные результаты и исправленные незавершённые серии.

## Данные и версии

Git хранит пакет, тесты, конфигурации, документацию и архивные прототипы.
results/work/.venv/.idea не входят в историю. Измерения, frozen manifest, source
snapshot, метаданные и журналы сохраняются отдельными проверяемыми архивами.
`bundle --output NEW.zip` формирует исходники с SHA256 и не перезаписывает файл.

Подготовленный CI делает установку, стиль, тесты и короткий smoke, а не полную
сериию исследования. Внешний прогон пока не выполнен. Локальные Git/ZIP на одном
Mac не заменяют внешнее резервное хранение.

## Контракт и две основы

`contracts/`: `npm ci`, затем `npm run build`. Версия solc закреплена; CI пересобирает
artifact и проверяет совпадение с Git. Контрактный gas не является квотой PD.
Любое изменение формата commitment/shuffle требует общей проверки Solidity/Python.
Нельзя называть локальный BLS test beacon публичным drand или локальную EVM
независимой BFT-сетью. Жёсткий guard состава не обходится ради прохождения раунда.

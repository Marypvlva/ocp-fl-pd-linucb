# История версий

## 0.4.0 — совместная основа OCP-FL и PD-LinUCB

- Контракт commit/reveal, Keccak, unbiased shuffle, будущий beacon slot.
- BLS/drand проверяется независимо до TCP; тест реальной подписи.
- Проверяемый состав участников и корректные веса выбранных обновлений.
- Совместный train/smoke/study стал основным, PD-only оставлен явно.
- Аудит обеих основ и траектории MLP; кредиты и gas разделены.
- Ограничения локальной EVM/oracle и контрпример selective-abort документированы.

Совместная проверка: 118 тестов, 15 сценарных запусков. Train: loss 0.218312, 124 обновлений, 248/400 кредитов. Локальная EVM и test beacon явно отделены от production-развёртывания.

## 0.3.0 — PD-LinUCB по статье автора

- Отдельное ядро: UCB−dual×cost, Sherman–Morrison, отложенные labels.
- Known-credit stop-at-budget, без списания или запуска недопустимого действия.
- Контекст TCP-стенда и два явно различаемых bounded reward.
- Команда train с PD-выбором каждого действия; контроль eta=0 и четыре fixed.
- Независимый матричный аудит и новые тесты бюджета/причинности.

PD-пилот: 48 запусков, независимый аудит пройден, первичное преимущество
не подтвердилось (−1.5 обновления [−6; +3]). Итоги сохранены без подбора
параметров после проверки.

## 0.2.0 — структура и проверка длительных режимов

- Рабочий пакет adaptive_planning, console entry point, совместимый project.py.
- 23 старых прототипа отделены, исторические исходники и измерения сохранены.
- Математика MLP и разбиение Digits перенесены без изменения и проверены.
- README сокращён, документация разделена на сопровождение и протоколы.
- Stateful-правило доступности и сравнение с лучшим из всех четырёх fixed.

## Предшествующие этапы

- Настоящее TCP-обучение вместо моделируемого времени.
- Статические/динамические ограничения каналов и криптографическая проверка.
- Условный выигрыш обучения при точной телеметрии, ухудшение при задержке.
- Согласование меток отчёта/стоимости; возрастная смесь при выборе.
- Локальный Git, диагностика, реестр, архивы и проверка восстановления.

Числа, конфигурации и ограничения сохраняются в docs/experiments и исходных сериях.

Независимая серия завершена: delayed -2.626 s [-3.419; -1.839], fast -0.287 s [-1.523; +0.948]. Все условия сохранены отдельно.

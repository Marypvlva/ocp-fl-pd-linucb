# Исторические прототипы

В `prototypes/` сохранены 23 старых скрипта с исходными именами и содержимым.
Они не импортируются рабочим стендом. Числа из симуляций и калибровок не являются
измерениями физического распределённого обучения.

Просмотр списка: `.venv/bin/python -m legacy --list`.
Явный запуск: `.venv/bin/python -m legacy aggregation_selftest`.
Launcher копирует исходники в новую уникальную папку `results/legacy_*`, поэтому
старые результаты не перезаписываются. Точные старые версии зависимостей и команд
содержатся в source snapshot соответствующей исторической серии.

Из старого `training_experiment.py` в рабочий `adaptive_planning/training.py`
перенесены только MLP и разбиение данных, без изменения численного алгоритма.
Совпадение проверяется отдельным регрессионным тестом.
